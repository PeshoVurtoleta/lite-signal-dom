What you're proving. Both panels show the same list, driven by the same signal. Hit STRESS ×60. The keyed panel rearranges the existing nodes — created never moves, every shuffle is pure insertBefore. The naive panel throws its DOM away and rebuilds, so created rockets up by the row count each time — that's the garbage a virtual-DOM or rebuild approach hands the collector every frame. Mutate one changes a single row's value: only that chip flashes, and the list never re-renders, because per-row bindings are independent of the reconciler.
